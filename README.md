# 🚗 Ejercicio Práctico: API REST con Java y Spring Boot

## 🎓 Sobre este Taller
Este repositorio es una guía práctica enfocada en el desarrollo de servicios web utilizando el ecosistema de **Spring Boot**. En este ejercicio, los estudiantes del **Instituto Movilis** aprenderán a construir una API robusta para la gestión de un inventario de automóviles, aplicando principios de Clean Code y arquitectura multicapa.

> **Nota del Instructor:** El desarrollo backend moderno no solo trata de conectar una base de datos con un cliente; se trata de construir servicios escalables, seguros y fáciles de mantener mediante la inversión de control y el manejo de dependencias.

## 🎯 Objetivos de Aprendizaje
A través de este proyecto, el estudiante dominará las competencias clave de un desarrollador Java Backend:
- [x] **Spring Web:** Creación de controladores REST (`@RestController`) y manejo de verbos HTTP (GET, POST, PUT, DELETE).
- [x] **Inyección de Dependencias:** Uso de `@Service` e `Inyección por constructor` para desacoplar la lógica de negocio.
- [x] **Integración Continua (CI):** Automatización de flujos de trabajo con **GitHub Actions** y análisis de cobertura de código con **CodeCov**.

## ⚙️ Integración Continua y Calidad
Para garantizar la estabilidad y confiabilidad del código, este repositorio integra herramientas de DevOps esenciales:
* **GitHub Actions:** Ejecuta automáticamente el pipeline de compilación y pruebas (`mvn test`) ante cada cambio en el código.
* **CodeCov:** Proporciona informes detallados sobre qué porcentaje de nuestra lógica está cubierta por pruebas unitarias, facilitando la detección de áreas críticas sin testear.

## 📂 Estructura del Repositorio
El código está organizado siguiendo las convenciones estándar de Maven y Spring:

```text
 📁 src/main/java/com/krakedev/auto
 ├── 📁 controlador  <-- Puntos de entrada de la API (EndPoints)
 ├── 📁 sservicio    <-- Lógica de negocio y procesamiento
 ├── 📁 entidad      <-- Entidades y modelos de datos
📁 src/main/resources
 └── 📄 application.properties <-- Configuración del entorno
📁 src/test  <-- Pruebas unitarias del proyecto
```
